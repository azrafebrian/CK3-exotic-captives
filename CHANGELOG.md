Change History:

Version 1.0 = (10 November 2026)

    - Release.

Version 1.1 = (14 November 2026)

    - Region Selector: Select which region the captives are taken from.
    - Price Scaling: Costs are now adjusted depending on your title rank.
    - Added a chance for captured captives to be of noble blood.
    - Added a modifier for captives, increasing the chance of their children having a good trait.
    - Adjusted the duration it takes for merchants to retrieve your captives.
    - Adjusted captives weight.

    - Fixed several text errors.
    - Fixed highlighted words.
    - Fixed issues with regions and sub-regions.
    - New update thumbnail.

Version 1.2 = (21 November 2026)

    - Compatibility update with game version 1.21.
    - Re-work on captive selector, now able to decide each captives fate, one by one.
    - Added a new options to set them free, unlike taken in captives, they are free to leave the court.
    - Freed captives are leaving the court after 1 year if they aren't tied.
    - Taken in captives now on a leash, force return them if they wander out of your court.
    - Added new modifier for freed captives.
    - Adjusting cost mechanism, decision cost is base cost, seperate cost for captives taken in or freed.
    - Lowering base cost to 75 gold (default price).

    - New update thumbnail.

Version 1.3 = (22 November 2026)

    - Adjusted base cost value to 50 gold, 100 prestige, 100 piety.
    - Adjusted root and captives modifiers.
    - Added expiry time for some modifiers.
    - Added character interaction: Set Free Captives.
    
    - Fixed some text errors in localization.
    - Fixed bug where captive modifier not get removed.
    - Fixed character position in event.
    - New update thumbnail.
