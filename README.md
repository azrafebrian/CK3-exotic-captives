# Exotic Captives

Adds Receive Exotic Captives decision, allowing you to get a character from far-away lands with different culture and faith than yours.

## Installation and Use

1. Go To https://github.com/azrafebrian/CK3-exotic-captives/releases and find the latest version, and **download**.
2. Extract the downloaded .zip file.
3. Copy or move halfsade_captives folder and halfsade_captives.mod into \Documents\Paradox Interactive\Crusader Kings III\mod
4. Open the game launcher and add mod to a playset, and enable the mod. 
5. Play game with selected playset.

## About This Mod

### Features

1. Receive Exotic Captives decision that brings a few characters from far-away lands to your court. Located in personal decision group.
2. Take all of the presented characters, pick only one, or return them.

### Requirements

Cost 200 golds, 250 prestige, and 250 piety

### Effects

1. Add new randomly generated character of a distant far away culture to your court.
2. Opinion modifier for your character.

### Limitations

1. Decision cooldown for 2 years.
2. Presented characters are all adult with age range from 16 to 30.
3. AI will not be able to do this decision.

### Additional Info:

1. If you're playing as male, presented characters are 85% female and 15% male.
2. If you're playing as female, presented characters are 85% male and 15% female.
3. 10% chance of presented characters having good inheritable traits.
